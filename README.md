**KrinSranan** is een open-source platform ontworpen om armoede te bestrijden, milieuvervuiling acuut te stoppen en corruptie aan de top onmogelijk te maken. 

Dit is GEEN Chinees controlesysteem. Dit is een digitaal sociaal contract, gebouwd DOOR integere burgers, VOOR het Surinaamse volk.

## 🚀 Kernfunctionaliteiten (Alles-in-één App)
* **Krin Wallet (Armoedebestrijding):** Lever plastic of vuilnis in en ontvang direct digitaal tegoed op je telefoon voor basisgoederen, EBS en water.
* **Onomkoopbare Code:** Geen politicus of ambtenaar kan handmatig scores aanpassen of hulppakketten achterhouden. De code voert de regels feilloos uit.
* **De Volksjury (De Loophole):** Onterecht gestraft door het systeem? Een volledig anonieme, willekeurige digitale volksjury van mede-Surinamers weegt de menselijke context en corrigeert het systeem via de app.
* **Anonieme Klokkenluider:** Upload bewijs van corruptie of kwikvervuiling. Je identiteit wordt direct cryptografisch gewist, en bij een succesvolle veroordeling keert het systeem automatisch een bonus uit.

## 🛠️ Technische Status
De kernarchitectuur (`krin_sranan_core.py`) is geschreven in Python en maakt gebruik van onwijzigbare hashing-ketens. Dit project is 100% transparant. Iedereen kan de code controleren op achterdeurtjes.
