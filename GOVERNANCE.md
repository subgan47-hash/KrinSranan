# ⚖️ KrinSranan Beheerreglement (Governance)

Dit document legt de onwijzigbare regels vast voor het beheer en de updates van de KrinSranan-applicatie. Het doel is om te voorkomen dat politici, overheden of individuele personen de controle over het systeem kunnen overnemen of manipuleren.

## 1. Open-Source & Publiek Toezicht
* **Harde Regel:** De broncode van KrinSranan zal ALTIJD 100% openbaar en in te zien blijven via deze GitHub-repository. 
* Het is ten strengste verboden om delen van de code geheim te maken of te verplaatsen naar private overheidsservers.

## 2. Updates via Digitale Democratie (Geen Politieke Inbreng)
* Geen enkele minister, president of IT-beheerder kan in zijn eentje de regels of de code van de app aanpassen.
* Wijzigingen in de code (zoals het aanpassen van de score-berekening of wallet-tarieven) kunnen ALLEEN worden doorgevoerd via een openbaar voorstel op GitHub (een zogenaamde *Pull Request*).
* Dit voorstel moet minimaal 14 dagen openstaan en publiek worden goedgekeurd door een onafhankelijke commissie van Surinaamse IT-studenten, cybersecurity-experts en vertegenwoordigers van burgerrechtenorganisaties.

## 3. Bescherming van de Beheerders
* De personen die de GitHub-repository technisch onderhouden (de *maintainers*) handelen uitsluitend als uitvoerders van de gemeenschap.
* Indien een beheerder onder politieke druk of dwang wordt gezet om de code aan te passen, verplicht de gemeenschap zich om de code direct te kopiëren naar een nieuwe, anonieme locatie (*forken*) om de onafhankelijkheid te waarborgen.
